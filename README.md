# Lagerprogramm für Zuhause

## Aktuelle Version: v0.7.0

### v0.7.0 – Mobile Lagerliste
- Eigene Kartenansicht für Artikel auf Smartphones; die Desktop-Tabelle bleibt auf größeren Bildschirmen erhalten.
- Menge und Bestandsstatus werden in der mobilen Karte gemeinsam dargestellt.
- Bearbeiten und Löschen sind auf Mobilgeräten über ein Drei-Punkte-Menü erreichbar.

### v0.6.4 – Einladungsverwaltung
- Angenommene Einladungen aus der offenen Übersicht ausblenden.
- Offene und abgelaufene Einladungen mit Status anzeigen.

### v0.6.2 – Haushaltsverwaltung
- Mitglieder, Rollen und Einladungen verwalten.
- Besitzer- und Administratorrechte unterscheiden.
